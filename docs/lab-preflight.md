# Checklist préflight (à compléter individuellement)

- [ ] VMware Workstation Pro démarre
- [ ] Au moins 16 Go de RAM et 8 processeurs logiques relevés
- [ ] Espace libre sur le poste relevé
- [ ] Virtualisation firmware renseignée (VT-x/AMD-V)
- [ ] État Hyper-V / VBS documenté (sans désactivation non autorisée)
- [ ] VMware NAT et réseau interne identifiés
- [ ] ISO Proxmox téléchargée et empreinte SHA256 comparée
- [ ] VM Proxmox créée sur disque virtuel uniquement
- [ ] Accès HTTPS sur le port 8006
- [ ] /dev/kvm présent ou parcours alternatif choisi
