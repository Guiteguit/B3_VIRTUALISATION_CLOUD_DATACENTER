# B3 — Virtualisation Cloud & Datacenter

3ESGI ALT · T1 · SRC · Tours — 12 heures, 8 modules de 1 h 30.

> Dépôt des étudiants. Formation progressive à VMware Workstation, Proxmox VE, KVM, LXC, réseau, stockage, sauvegardes et Cloud-Init.

## Objectif

Construire et exploiter individuellement un mini-datacenter NovaCorp dans Proxmox imbriqué sous VMware Workstation, pour préparer les apprentissages avancés du M1.

Les supports détaillés arrivent dans une Pull Request dédiée.
