# M06 — Défi interactif NovaCorp

**Brief client (10 min) :** Une erreur applicative efface un fichier critique : la direction demande une preuve de reprise.

**Question de départ / prédiction :** Comparer snapshot et backup ; anticiper RPO/RTO à l'oral.

**Revue croisée (10 min) :** Un pair joue l'auditeur et demande la preuve du fichier récupéré sur un CT distinct.

**Variante du second sprint :** Le client annonce une panne de l'hôte entier : expliquer pourquoi le backup local est insuffisant.

**Rendu du module :** Journal d'horodatage + sauvegarde, restauration ID 201, données récupérées, RTO mesuré.

## Comment faire la revue sans perdre son autonomie
- Chaque étudiant configure **son propre** environnement.
- Le pair demande une preuve non destructive, ne change pas l'environnement à la place du propriétaire.
- Une personne explique son hypothèse, l'autre la teste. On inverse les casquettes au module suivant.
- On dépose la conclusion dans le [modèle de rendu](../docs/modele-rendu-interactif.md).
